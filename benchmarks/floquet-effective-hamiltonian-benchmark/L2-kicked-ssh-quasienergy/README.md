# L2 Kicked SSH Quasienergy

This runnable task packages the accepted L2 reference
`flq_l2_kicked_ssh_quasienergy_formula` from
`../data/floquet_reference.csv`.

It evaluates the Z-kick Floquet quasienergy formula from paper
`812585024850231297`, varying h-vector samples and kick strengths in hidden
cases.

Run:

```bash
bash scripts/selfcheck.sh
```
