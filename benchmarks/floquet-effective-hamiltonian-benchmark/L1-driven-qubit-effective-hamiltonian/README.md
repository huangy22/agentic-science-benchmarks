# L1 - Driven Qubit Effective Hamiltonian

Implement a generic solver for a sinusoidally driven two-level system and recover
effective Floquet Hamiltonian components, the quasienergy gap, and a stroboscopic
transition probability. This is the smallest numeric instantiation of workflow
family `#1069`.

```bash
bash scripts/selfcheck.sh
```
